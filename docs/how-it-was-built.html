The most serious bug of the session, and five words found it. The API had hung completely — every request, including the health check. The reloader had noticed a file change, tried to restart, and waited forever for connections to close, because the new event stream never ends. APPENDIX

What the other side looked like

Thirty prompts, most of them under ten words, produced 713 tool calls. The ratio is the point: the instructions were short and the work underneath them wasn't.

The three prompts that mattered most were the shortest. “are you selling anything?” found a code path that had never run. “cash is not changing” found a page that never refreshed and a rounding bug behind it. “Loading portfolio…” found a completely wedged API. None of them described a symptom in any detail; each one just reported, accurately, what was on the screen.

Worth saying plainly: the agent is a simulation. It trades invented companies with invented money, there is no path to a live venue in the code, and the honest backtest result was left in the repo unflattered — the agent returned 46% against buy-and-hold's 111% over the same period, at half the volatility.
